**EduVerify** is an interactive digital literacy platform tailored for the Indonesian youth. Unlike traditional educational tools, EduVerify focuses on empowering users to think critically and independently through bite-sized visual content, real-world case studies, and interactive assessments.

🔗 **[Live Demo Link](https://eduverify-digital-literacy-education.vercel.app)**

---

## ✨ Core Features & Learning Modules

EduVerify delivers its educational framework through three core pillars:
* **Visual & Fact-Based Learning:** Bite-sized, engaging visual materials instead of overwhelming textbook prose.
* **Real-World Case Studies:** Practical analysis of viral hoaxes that have actually occurred in Indonesia.
* **Interactive Quizzes:** Real-time critical thinking tests with instant feedback to help users identify gaps in their logic.

### 📚 Learning Modules
The platform is structured into three specialized learning tracks:
1.  **Detektif Digital (Digital Detective)**
2.  **Teknik Verifikasi (Verification Techniques)**
3.  **Psikologi Hoaks (The Psychology of Hoaxes)**

## 🛠️ Tech Stack

Built with a focus on high performance, clean code, and zero framework overhead.

* **Frontend & Styling:** HTML5 & **Tailwind CSS v4** (via CDN) for modern, utility-first rapid styling.
* **Core Logic:** **Vanilla JavaScript (Pure JS)**. All core interactive features—including quiz state management, live score tracking (`ddSkor`, `tvSkor`, `phSkor`), DOM manipulation, and quiz reset states—are built from scratch.
* **Libraries:**
    * [Boxicons](https://boxicons.com/) for consistent, clean iconography.
    * [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) for smooth scroll-based visual engagement.
    * [Typed.js](https://mattboldt.github.io/typed.js/) for an interactive, dynamic typing effect in the hero section.
